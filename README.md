# Automação QA

Repositório criado para reunir os códigos utilizados e desenvolvidos durante as aulas de **Nivelamento Typescript**, além de atividades e exercícios para prática dos conteúdos estudados.

## 📂 Estrutura do repositório

### 📂 Atividades

Nesta pasta estão os códigos das **atividades realizadas pelos alunos durante as aulas**.

São exercícios propostos para colocar em prática os conteúdos apresentados em cada aula.

### 📂 Aula 25, Aula 26, Aula 27, Aula 28 e Aula 29

Cada pasta contém os **códigos desenvolvidos durante a respectiva aula**.

Os conteúdos e códigos de cada aula também estão apresentados nos slides, junto com a indicação da **unidade** à qual a aula pertence.

Por exemplo:

* **Aulas 28 e 29 → Unidade 11**
* Os códigos dessas aulas correspondem aos conteúdos apresentados nos respectivos slides.

### 📂 Exercícios

Esta pasta foi criada para **prática e fixação dos conteúdos estudados em aula**.

Os códigos disponibilizados possuem partes incompletas, e a proposta é que os alunos **identifiquem e adicionem os códigos que estão faltando**, utilizando como base os conhecimentos adquiridos durante as aulas.

Os exercícios foram elaborados de acordo com os conteúdos que já foram apresentados, permitindo que os alunos pratiquem a programação de forma mais independente.

### 📂 Testes

Nesta pasta estão os códigos relacionados aos **testes automatizados trabalhados durante as aulas**, utilizando o **Vitest**.

Também está disponível o arquivo `soma.test.ts`, que apresenta um conteúdo complementar relacionado aos **matchers do Vitest**.

Esse conteúdo não foi abordado diretamente durante as aulas. Por isso, o próprio arquivo contém **comentários explicativos e um tutorial**, permitindo que os alunos entendam como o código funciona e possam explorar esse recurso de forma independente.

## Objetivo

O objetivo deste repositório é centralizar os materiais práticos utilizados durante as aulas e oferecer aos alunos um espaço para **consultar exemplos, revisar conteúdos e praticar programação e testes automatizados**.
